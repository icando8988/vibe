# 프로젝트 에이전트 진입 지침

AI_TEAM_RULES.md와 .ai/PROJECT.md, .ai/TEAM.md, .ai/TRANSPORT.md를 먼저 읽는다.
현재 활성 Master는 CX-MASTER-01이다. 추가 Codex는 명시적으로 배정된 작업자이며 Master를 자칭하지 않는다.
작업 ID·수정 범위·완료 조건을 기록한다. .ai/roles/의 해당 역할 지침을 따른다.
현재 폴더는 Git 저장소가 아니다. Git 초기화나 앱 구현은 계획 검토 단계 이후 별도 작업으로 진행한다.
API KEY.txt와 비밀번호 파일은 기획 분석 입력이 아니다. 내용 읽기·문서 포함·커밋을 하지 않는다.
