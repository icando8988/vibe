# 배포 결과 근거·집계 기술 결정

CX-MASTER-01 / QA-MKT-001 검토 / 2026-11-16. 실제 공급자 미연결 유지.
1 live 결과 반영에는 유효한 시도번호 필수. dry_run만 선택인자 호환 유지. 시도번호 미입력/오염/과거 결과는 현재 결과를 덮지 않는다.
2 취소/실패/구시도 뒤 도착한 게시 증거를 자동 폐기하지 않는다. 별도 순수 검증 결과로 보존하고 requires_reconciliation=true를 돌려 운영 저장 계층에서 감사/재시도 차단하도록 계약. 현재 저장 계층은 없으므로 실제 보장이라고 하지 않는다. 기존 published 근거와 충돌하면 보존·수동 대사, 자동 상태 변경 금지.
3 게시 근거 URL은 null 또는 credentials 없는 HTTPS만. HTTP/javascript/data/비어있는 URL 문자열 거절. 외부 식별자만 있어도 게시 증거로 허용하되 실제 provider 조회 검증은 이후 단계.
4 작업id는 비어있지 않은 제한된 길이의 안전 ASCII 식별자로 검증. 기존 샘플 호환 범위를 유지.
5 전체 이력 요약과 특정 콘텐츠버전 채널 요약을 분리. 여러 콘텐츠/버전을 합쳐 현재 배포성과처럼 표시하지 않는다. 원래 함수의 뜻을 몰래 바꾸지 않고 explicit scope API 또는 별도 함수 제공.
