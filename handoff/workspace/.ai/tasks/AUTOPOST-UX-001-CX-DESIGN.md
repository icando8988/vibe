# AUTOPOST-UX-001 — 통합 게시 콘솔 UX 명세

- 작업 ID: AUTOPOST-UX-001
- 담당: Codex Design (CX-DESIGN)
- Master: CX-MASTER-01
- 기준: `docs/AUTOPOST_INTEGRATION_PLAN.md`, 기존 `web/` UI 구조/스타일만
- 출력: `.ai/results/AUTOPOST-UX-001-CX-DESIGN.md`

## 목표

기존 사이트 안에서 Blog 수동 배포, Threads, Instagram 게시를 운영하는 통합 콘솔의 UX 명세를 작성한다. 구현 코드는 작성하지 않는다. 키트 소스, 화면, 프롬프트, 스키마를 열거나 재사용하지 않는다. 제공된 통합 플랜의 요구사항만 사용한다.

## 범위

1. 내 콘텐츠/배포 작업 목록과 검색·필터·정렬·상태 배지.
2. 원본 편집 및 버전 관리, 채널별 문안/미디어/링크 미리보기와 검증.
3. 승인·재승인·예약 또는 즉시 실행 전 확인 UX.
4. 블로그 수동 내보내기, 게시 확인 및 URL/외부 ID 증거 입력.
5. Threads/Instagram 연결 상태, 권한 만료/재인증, 예약 상태.
6. `unknown` 대사 전용 화면: 자동 재시도 차단, 확인 근거 기록, published/absence/still unknown 분기.
7. 일부 채널 성공/실패/대기 혼합 결과, 지연·실패·취소·재인증 안내.
8. 모바일, 키보드, 접근성, 빈 상태, 오류 상태, 파괴적 행위 확인.

## 제약과 완료 조건

- 기존 `web/`의 현재 UI 패턴을 실제 파일만 읽어 파악하고 파일 경로를 근거로 기록한다.
- 제품 UX/상태/화면 흐름 명세만 제출한다. 코드, DB, SQL, 이미지 자산, 테스트는 만들거나 실행하지 않는다.
- 키트 코드/화면을 열지 않는다. API 정책 세부사항을 추정하지 말고 `unverified` 상태와 readiness 의존성으로 표현한다.
- 화면별 목적, 핵심 요소, 주요 액션, 실패/경계 상태, 접근성 기준, 상태 전이를 명확히 적는다.
- 마지막에 Master가 결정해야 할 UX 질문과 구현 순서를 적는다.
