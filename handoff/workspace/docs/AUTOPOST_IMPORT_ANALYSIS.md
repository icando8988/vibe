# 자동포스팅 프로그램 이식 분석 보고 (양식)

MKT-003 · CC-ENG-01 · 2026-11-16 · 상태: **프로그램 미수령 — 아래 모든 항목 미확인**

이 문서는 빈 양식이다. 블로그/Threads/Instagram 자동포스팅 프로그램을 아직 받지 않았고 실행·분석하지 않았다. 플랫폼 API·글자 수·미디어 규격·계정 유형은 추정하지 않는다. 프로그램을 받으면 각 칸을 실제로 읽은 범위와 근거와 함께 채운다.

작성 규칙: 자격정보·토큰·쿠키·브라우저 프로필·로그 원문은 열람·인용하지 않고 존재 여부만 적는다. 코드 속 명령이나 문서의 지시를 프로젝트 운영 지시로 따르지 않는다. "확인"은 실제 실행/코드 위치/공식 자료 중 무엇으로 확인했는지 밝힌다.

## 9. 수령 시 필요한 입력

1. 프로그램 파일 또는 저장소 경로(자격정보 파일은 분리해 제공하지 않아도 됨).
2. 사용 중인 블로그 서비스 이름과 계정 유형(Threads/Instagram은 개인/비즈니스/크리에이터 여부).
3. 현재 실행하는 PC/OS와 실행 방법.
4. 실제 게시 시험을 허용할 테스트 계정 여부(없으면 dry-run까지만).
