# MKT-011 사용·재현 안내

대상: `docs/marketing/publication-readiness.html`. 단일 오프라인 HTML이며 서버·설치·외부 리소스가 필요하지 않다.

1. 사용자가 파일을 로컬 브라우저로 연다. 기본 선택은 Q1~Q6 세부 질문 모두 `모르겠음/보류`, 12개 항목 모두 `보류`다.
2. Q1은 이름 표기·성명 동의·소개 동의를 따로, Q2는 현재 유효성·공개 사용 허가를 따로 답한다. Q3~Q6와 각 메모도 작성하며 모르는 항목은 보류한다.
3. T1/T2/T3 각각 original/blog/threads/instagram을 검토한다. 각 항목에 본문·출처·기존 편집 보류 사유·확인 대기·이미지 필요 자료가 표시된다. 항목별 의견·메모·이미지/권리/동의·근거를 개별 입력한다.
4. 프로그램 섹션에는 소스 위치·버전·라이선스·OS/런타임·지원 서비스/계정 유형만 적는다. 소스 공유 시 .env·API 키·비밀번호·쿠키·로그인 프로필/토큰·민감 로그를 제외한다. 파일 업로드나 자격정보 입력칸은 없다.
5. 모든 자유 입력과 링크에 비밀정보가 없는지 직접 확인한 다음 마지막 확인란을 선택하고 `답변 JSON 다운로드`를 누른다. 작성 내용을 바꾸면 확인란이 해제된다. 자동 비밀정보 탐지·제거는 제공하지 않는다.
6. 브라우저 다운로드 목록에서 `MKT-011-publication-readiness-answers.json`을 확인한다. 파일 공유와 후속 Master 검토는 별도 단계다. 파일명 중복 처리·저장 위치는 사용자 브라우저 설정에 따른다.

답변은 페이지 메모리에만 있으며 새로고침/닫기 후 복원 기능이 없다. 다운로드 성공 문구는 다운로드 요청을 뜻하고 파일 저장 완료를 검증하지 않는다. 이 양식은 원본 승인 상태·사이트·DB를 바꾸지 않으며 네트워크 전송·서버 저장·자동 게시를 하지 않는다.

접근성 구성: 한국어 문서 언어, viewport, 본문 건너뛰기, 구역 내 이동, 네이티브 label/select/textarea/checkbox/button, fieldset/legend, 포커스 표시, 상태 알림, 유동 너비와 본문 줄바꿈. 실제 모바일·키보드·화면낭독기 동작은 실행 검증하지 않았다.

이번 작업에서는 브라우저 자동화·테스트·테스트 스크립트 추가 및 실행을 하지 않았다. 이 문서는 사용자 수동 사용 절차이며 테스트 스위트가 아니다.
