# 첫 콘텐츠 묶음 독립 편집 검토

MKT-009 · 검토자 CC-ENG-01(Claude Code) · 2026-11-16. 대상 작성자는 MKT-007 담당이며, 이 검토는 다른 담당의 **독립 검토**다.
대상: `docs/marketing/first-content-pack.md`(원문 3 + 변형 9, 전부 읽음), `first-content-pack.json`(구조·상태값·본문 일치 점검), `planning-source-extracted.txt`의 E17·E18·E19·E24·E25·E48·E49 셀, `docs/MARKETING_DELIVERY_PLAN.md`.

이 문서는 수정 **제안**이다. 원문·JSON은 바꾸지 않았고 공개 승인 판단도 하지 않는다. 실제 게시 적합성·플랫폼 정책 준수·성과는 판정하지 않는다. 자동포스팅 프로그램 미수령·채널 규격 미확인 상태는 그대로다.

## 1. 요약 판정

- **사실 정확성: 양호.** 원고는 기획서에 없는 경험·인터뷰·감정·실적·기록 인증·출판 확정을 만들지 않았다. JSON에서도 `publicationApproved=true`나 draft가 아닌 상태는 없다.
- **공개 독자용 글로는 아직 쓸 수 없다.** 본문 대부분이 "초안입니다·제안합니다·확인이 필요합니다·사용하지 않습니다" 같은 **내부 검토 문장**이다. 독자가 얻는 정보가 거의 없다.
- **확인된 계획 정보를 쓰지 않았다.** 기획서 E49에 있는 출발 예정일·출발지·구간 수·단독 여정은 계획으로 표기하면 쓸 수 있다. 사이트 `/about`도 이미 출발 예정일을 보여준다. 그런데 원고는 이를 빼고 "어떤 여정을 구상하는지"처럼 모호하게만 말한다.
- **주제 2(준비 기록)는 실제 준비 자료가 없어 독자용 본문을 만들기 어렵다.** 보류를 권장한다.

## 4. 공개 독자용 본문과 검토 주석 분리 — 주제당 예시 1개

확인된 계획(E17·E49)만 사용했다. 날짜·구간·단독 여정은 원문 셀 그대로이며 "계획"으로 표기했다. 확인되지 않은 것(거리 수치·출판 시기·크라우드펀딩·기네스·준비 현황)은 넣지 않았다. **예시이며 원문 반영 아님.**

### 주제 1 예시 (블로그 길이)

> **2029년 봄, 부산항에서 시작하는 자전거 세계일주 계획**
>
> 원민철은 2029년 3월 15일 부산항을 떠나 자전거로 세계를 일주하는 여정을 계획하고 있습니다. 계획한 여정은 13개 구간으로, 자전거로 달리는 구간과 비행기·배로 건너는 구간을 이어 혼자 다녀온 뒤 집으로 돌아오는 일정입니다.
>
> 이 여정의 이야기는 전자책과 종이책으로 펴낼 계획입니다. 출발 전까지의 계획과 준비 과정을 이곳에 차례로 소개하겠습니다.
>
> → 도전 소개 보기 (`/about`)

검토 주석(비공개): 근거 E49(날짜·출발지·13구간·혼자), E17(전자책·종이책). 전부 계획. 거리 수치 미사용(Q2). 기네스·최고령 미사용(총괄 9절). "차례로 소개하겠습니다"는 운영 약속이라 게시 주기 확정 전 문구 확인 필요(Q5). 호칭 확인(Q1).

### 주제 2 예시 (보류 권장. 진행할 경우)

> **출발까지, 무엇을 준비하는지 기록합니다**
>
> 2029년 3월 출발을 목표로 한 자전거 세계일주 계획에는 13개 구간이 있습니다. 앞으로 각 구간을 어떻게 나누고, 자전거로 달릴 길과 비행기·배로 건널 길을 어떻게 이을지 준비하는 과정을 기록해 나갈 예정입니다.

검토 주석(비공개): 실제 준비 항목·진행 상황 자료가 없음. "준비하는 과정을 기록"은 실제 기록 활동을 전제하므로 당사자 확인 전 게시 불가(Q3). 사진·장비·훈련 언급 금지 유지.

### 주제 3 예시 (Threads 길이)

> 자전거 세계일주의 이야기를 전자책과 종이책으로 펴낼 계획입니다. 책의 제목과 내용, 펴내는 시기는 정해지는 대로 알려 드릴게요.

검토 주석(비공개): 근거 E17. 제목·목차·출간일·가격·판매·후원 미언급. 크라우드펀딩 언급 여부는 Q4. "알려 드릴게요"는 후속 안내 약속이라 확인 필요(Q5).
