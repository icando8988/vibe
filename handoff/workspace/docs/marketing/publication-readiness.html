콘텐츠 발행 준비 확인

질문 6개, 원문 3개·채널 변형 9개, 이미지·권리와 프로그램 정보를 한 번에 정리합니다. 답변은 전부 보류에서 시작합니다.

다운로드만 하는 오프라인 양식입니다.

외부 요청·서버 저장·자동 저장·계정 연결·자동 발행이 없습니다. 새로고침하거나 닫으면 작성 중 답변이 사라질 수 있습니다. 다운로드 버튼은 답변 JSON 파일만 만듭니다.

사이트 실명 공개 동의, 공개 저장소 실명 유지 승인, 각 게시물의 공개 승인은 서로 별개입니다. 여기서 ‘승인 가능’을 선택해도 원문·사이트·팩의 공개 승인 상태는 변경되지 않습니다. 미리보기나 답변 파일은 게시 허가를 자동 집행하지 않습니다.

일정·구간·출판은 출처에 적힌 계획이며 현재 확정·실적이 아닙니다. 원본 자료·권리·동의·채널 조건은 미확인입니다.

모든 입력칸에 .env, API 키, 비밀번호, 쿠키, 로그인 프로필/토큰 등 비밀정보를 넣지 마세요. 자유 입력의 비밀정보를 자동 판별하거나 제거하지 않습니다. 다운로드 전에 직접 확인하고 제거하세요.
